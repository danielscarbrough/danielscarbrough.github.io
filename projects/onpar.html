On-PAR Senior Project

My senior year at university, I participated in the On-PAR senior design team with thirteen other members, including a faculty sponsor. Our team was tasked with creating a putting aid device that would track and collect both errant and accurate putts. We designed a robot that could recognize golf balls using computer vision, estimate their position based on the machine vision bounding box, and collect the golf ball using drive motors and flywheels. Below is the final SolidWorks rendering for the robot.


As the most experienced programmer on the team, I became the team's lead software developer. I used a Raspberry Pi 5 running Ubuntu as the operating system of choice for the project, programming in Python. Early in the project's lifespan, I discovered the Robot Operating System (ROS 2), and taught myself the basics of ROS 2 to streamline the integration of motors and sensors. I spent the majority of the first semester coding the basic control system for the device. There are seven primary ROS nodes that work in unison to control the system. I have linked the folder that includes all the source code for the project, though without the ROS 2 file system included, the code has no functionality. I have included it in order to convey the scale and quality of the code.

The second semester, I shifted my focus to developing computer vision systems for golf ball tracking. After capturing and filtering images using OpenCV, I utilized Ultralytics' YOLO algorithm for recognition combined with a BOTSORT algorithm for tracking golf balls across multiple frames. I used the size of the bounding boxes to approximate the distance the golf ball was from the camera. The camera vision was tested at over 60 distances between 0 and 3 feet, resulting in an average 5" measurement error. The resting position of the golf ball was plotted onto the system's touchscreen display. Golf balls that pass the robot and go missing on the camera are marked by being grey in color. Additionally, the touchscreen allows for the user to pick the details of their putting session, and displays statistical data such as good, short, and long putts.


I finished my portion of the project a few weeks before presentations, so I spent the last few weeks of the project assisting the power systems team using my electrical engineering skills. I helped redesign some of the electrical wiring that was inefficient or failing, creating a tight wiring harness that sufficiently powered the system.
